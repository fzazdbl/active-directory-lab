# Active Directory Lab

> Lab complet Active Directory -- cours interactifs HTML et scripts PowerShell.

## Contenu

### Cours interactifs (HTML)
- Fondamentaux AD : Workgroup vs Domaine, SAM, NTLM, Kerberos, DNS SRV, FSMO
- Groupes et securite : AGDLP/AGULP, permissions NTFS/partage, permissions effectives

### Scripts PowerShell
- Create-OUStructure.ps1 -- Creation automatique d'OUs
- Import-ADUsers.ps1 -- Import d'utilisateurs depuis CSV
- Set-NTFSPermissions.ps1 -- Application de permissions NTFS selon AGDLP

### TPs
- Exercices AGDLP (domaines gemini.fr, sopra.fr)
